# Interactive Calculator & Unit Converter

InternCircle Python Programming — Project 01

## Features
- Addition, subtraction, multiplication, and division (with division-by-zero validation)
- Kilometers ↔ miles
- Celsius ↔ Fahrenheit
- USD ↔ INR using a clearly labeled **fixed demo exchange rate** (not a current market quote)
- Menu loops and input validation

## How to run
1. Install Python 3 if necessary, or use an online Python editor.
2. Run `python main.py`.
3. Choose a menu option and enter numeric values.
4. Select option 4 to exit.

## Sample checks
- 10 + 5 = 15
- 0°C = 32°F
- 10 km ≈ 6.2137 miles
- 2 USD = 170 INR at the demonstration rate

## Notes
Currency conversions are for learning only and do not retrieve live exchange rates. Test the program and adapt the project yourself before submission.
